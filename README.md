# Amazon Listing 优化 Skill

面向跨境电商运营团队的 Amazon Listing 优化工作流。适用于新品上架、老品优化、低转化和高退货整改。可以跑完整流程，也可以单独做页面审核、关键词布局或发布前检查。

**先核实产品事实，再诊断页面。运营确认修改方向后，生成目标站点文案和设计 Brief。**

## 快速开始

将仓库下载或克隆到工作区，保留目录结构。在 Codex 中打开该目录，明确要求按 [SKILL.md](SKILL.md) 执行。已经在 ChatGPT 中安装此 Skill 的用户，可以直接调用 `@amazon-listing-optimization`。

准备商品站点、品类、ASIN 或 SKU、产品说明书或事实表，以及现有 Listing（新品可用计划稿）。关键词数据、评论、退货原因和类目要求有多少提供多少。

**示例｜日本站麦克风转化整改**

> 请按 SKILL.md 执行阶段 4。目标是提升这款日本站 USB 麦克风的转化率。根据说明书、当前标题与五点、搜索词报告和评论完成审核。列出扣分证据、资料缺口和优先修改项，等我确认方向后再写日文文案并附中文对照。

## 流程与交付

| 环节 | 交付内容 |
| --- | --- |
| 准备 | 优化任务单、产品事实表、关键词与评论资料 |
| 诊断 | 百分制审核、逐项扣分证据、优先优化事项 |
| 内容制作 | 关键词布局、3 个标题、2 套五点、描述或 A+ 文案框架 |
| 素材规划 | 七图与视频 Brief、A+ 模块、Search Terms 候选 |
| 审核与复盘 | 三轮审核、人工发布确认、版本记录及上线后 7／14／28 天复盘 |

## 阶段 4｜百分制审核

| 评分维度 | 分值 |
| --- | ---: |
| 产品信息与准确性 | 20 |
| 关键词与搜索匹配 | 15 |
| 标题质量 | 10 |
| 五点与文案说服力 | 15 |
| 图片、视频与 A+ | 20 |
| 客户体验与预期管理 | 10 |
| 合规与风险 | 10 |
| **总分** | **100** |

审核报告给出评分汇总、详细扣分、一票否决检查、优先优化项和最终结论。每条扣分引用已提供的内容或数据。资料不足时标明待评分值。优先修改项标注主要影响指标，如曝光、CTR、CVR、退货率或合规风险。

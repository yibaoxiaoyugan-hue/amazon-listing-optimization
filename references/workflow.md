# AI 辅助 Amazon Listing 优化工作流

## 工作流目标与执行原则

用 AI 整理产品资料、分析关键词与客户声音、诊断和生成文案、规划设计素材、辅助审核与数据复盘。运营提供真实资料并作最终判断。未经核实的事实不进入文案。发布前人工审核，保留版本并用数据验证改动。

**完整顺序**：确定目标 → 建立事实表 → 收集页面、关键词、评论与竞品 → AI 诊断 → 关键词布局 → 撰写候选 → 规划素材 → 整理 Search Terms → 三轮审核 → 人工发布与记录 → 数据跟踪复盘。

## 团队分工

| 角色 | 职责 |
| --- | --- |
| 运营助理 | 收集产品、关键词、竞品、评论和后台数据 |
| AI | 分类、审核、生成草稿和检查一致性 |
| 运营负责人 | 确定目标、批准方案和发布 |
| 产品或采购 | 核实规格、配件、包装及适用限制 |
| 设计师 | 执行图片、视频和 A+ Brief |
| 合规人员 | 核验商标、认证、声明和类目风险 |

小团队可兼任角色，尽量让资料录入和最终审核由不同人员负责。

## 阶段 1｜建立优化任务单

从关键词覆盖、自然流量、点击、转化、退货、广告流量精准度、本地化、信息修正中选择一个主目标，次要目标另记。记录依据、负责人和预期上线时间。

**执行人**：运营负责人定方向，运营助理填写。
- 填写站点、ASIN/SKU、品类、父子体和变体、链接、任务类型（新品、老品、低转化、高退货）、目标客户、问题与数据期间、优化日期、负责人、预计上线日。
- 例如 Sessions 基本稳定而 Unit Session Percentage 连续两周下降，主目标选提升转化，次目标可写减少尺寸误解引发的退货。
- **交付与验收**：优化任务单。站点、ASIN/SKU、唯一主目标、负责人与上线日期明确。缺项标明待补及责任人，可先盘点资料。

## 阶段 2｜建立产品事实表

逐项核对包装、说明书、规格表、检测及认证文件或实测记录。标记适用变体、来源位置与状态。重点核实材质、尺寸、重量、数量、兼容与不兼容范围、配件和限制。认证、测试效果、专利和售后承诺须有匹配型号、适用范围与真实文件。

**执行人**：运营助理收集，产品或采购核实。
- 逐项登记品牌、名称、品类、型号、颜色、材质、尺寸、重量、包装数量及清单；核心与辅助功能、用法、场景、人群、适用及不适用型号、限制；真实差异、测试、认证、专利、售后、禁用词和容易误解的表述。
- 使用事实编号｜适用变体｜值及单位｜来源及页码｜状态（已确认、待确认、禁止使用）｜确认人。资料冲突记录双方来源并冻结相关卖点，仅用已确认事实生成候选文案。
- **交付与验收**：事实表与待确认清单。关键规格和兼容性可追溯，认证与测试有适用文件，口头描述不能单独支撑高风险卖点。

### 产品事实表

| 信息分组 | 待填写字段 |
| --- | --- |
| 基础信息 | 品牌、产品名称、类型、型号、颜色、材质、尺寸、重量、包装数量、包装清单 |
| 产品功能 | 核心功能、辅助功能、用法、场景、适用人群、适用型号、不适用型号、限制 |
| 差异化 | 与可比竞品的真实差异、测试结果、认证、可使用的专利、售后政策 |
| 风险 | 禁止宣传的功能和措辞、易误解信息、涉及的商标、待确认参数 |
| 来源 | 包装、说明书、供应商规格表、检测报告、认证文件、实测记录 |

| 事实编号 | 字段 | 值和单位 | 适用变体 | 来源及页码 | 状态 | 确认人 |
| --- | --- | --- | --- | --- | --- | --- |
| F01 |  |  |  |  | 已确认 / 待确认 / 禁止使用 |  |

已确认的事实可用于文案。待确认项目仅留在核实清单。禁止使用的项目从所有候选文案中排除。

## 阶段 3｜收集优化资料

保留现有标题、五点、描述、主副图、A+、视频、Search Terms、价格优惠、变体和快照。关键词可来自广告搜索词报告、出单词、品牌分析、站内建议和研究工具。收集本品评论、退货、问答、客服及 Voice of Customer。选择同站点 3–5 个在用途、规格或定价上可比的竞品，记录价格/Coupon、规格、包装、评分/评分数、标题、卖点、图序、A+及评论主题。样本不足照实标注。保留日期、样本分母与出处，用竞品发现需求，禁止复制素材或文案。

**执行人**：运营助理采集，AI 整理。
- 保存页面版本与时间，含标题、五点、描述、图片、A+、视频、Search Terms、价格优惠、变体和截图。新品无现页时用计划稿或标记不适用。
- 关键词记录原词、来源、期间、搜索量、相关性、广告订单、自然排名和品牌风险。来源还可包括竞品页面、评论及问答。
- 客户声音记录本品及竞品好差评、问答、客服、退货原因和 Voice of Customer。保留样本分母及原文引用，按尺寸、兼容、安装、使用等主题汇总。
- **交付与验收**：现页快照、关键词表、评论退货分析、竞品对比和缺口清单。核对同站点与变体、竞品可比性、字段来源与日期，未知值留空。

### 资料包填写表

| 数据表 | 字段 |
| --- | --- |
| 当前页面 | 站点、ASIN/SKU、变体、采集时间、标题、五点、描述、A+、主副图、视频、Search Terms、价格、优惠、截图 |
| 关键词 | 原词、来源、日期、热度或搜索量、相关性、广告订单、自然排名、品牌标记 |
| 客户声音 | 来源、期间、样本量及分母、原文或引用编号、提及次数、主题、退货原因、可处理位置 |
| 竞品 | 站点、ASIN、可比理由、定位、售价与 Coupon、标题、卖点、图序、A+、星级、评分数、好差评主题、规格与包装 |
| 待补资料 | 缺失项、影响的诊断环节、负责人、预计补齐时间 |

广告报告没有该词记录、确认零订单、未收录和暂无排名数据分别标记。竞品只用于识别需求和表达机会。

## 阶段 4｜AI 诊断当前 Listing

使用阶段 4 百分制审核标准，输出七项评分、证据与扣分、一票否决检查、优先优化项和最终结论。运营负责人确认方向后再生成文案。

**执行人**：AI 初评，运营复核搜索、点击、转化和本地化，产品或合规复核事实与风险。
- 汇总事实表、页面快照、词表、评论退货、竞品和类目要求。按 [阶段 4 审核标准](listing-audit.md) 逐项评分，检查误购与发布阻断，引用原文和证据。把页面可以修复的顾虑与应交产品、包装或说明书负责人的问题分别记录。
- 运营将事项标为必须修改、建议修改、暂不修改、需要补资料或不属于 Listing 问题。优先确认影响最大的 3–5 项。
- **交付与验收**：五段审核报告、证据、优先级和负责人决定。未证实判断标资料不足。确认方向后进入后续内容制作。


## 阶段 5｜关键词分层与布局

分类为品类、功能、属性、场景、人群、长尾购买、低相关、第三方品牌/商标风险。相关性优先于流量，搜索量缺失留空。核心品类和关键属性优先放标题，功能/场景/购买意图自然放五点，图片快速传达卖点与规格，A+展开用法、场景、规格对照和 FAQ。排除低相关、误导、竞品品牌词及未经授权的商标。

- **交付与验收**：按关键词｜词类｜相关性｜购买意图｜来源｜推荐位置｜已有覆盖｜风险｜使用建议输出布局表。标题避免同义词堆叠，后台词补前台未自然覆盖的高相关表达。

### 可复制提示词｜关键词布局

```text
基于已确认事实表、关键词数据和阶段 4 结论，对关键词分层。
逐词输出原词、词类、产品相关性（高/中/低）、购买意图（高/中/低）、数据来源、推荐位置、当前是否覆盖、品牌/商标或误导风险和使用建议。
优先考虑相关性和购买意图；搜索量缺失留空。排除竞品品牌和产品不具备的功能词。
```

| 位置 | 优先信息 |
| --- | --- |
| 标题 | 核心品类词和关键属性 |
| 五点 | 功能、场景和购买意图 |
| 图片 | 易读的卖点和规格 |
| A+ | 场景、用法、规格对照和 FAQ |
| Search Terms | 前台未自然覆盖的高相关表达 |
| 排除 | 低相关、误导和未经授权品牌词 |

## 阶段 6｜生成文案方案

给 3 个标题（覆盖型、卖点型、规格型）和 2 套五点（功能差异、场景顾虑），分别标出策略、关键词覆盖和事实编号。标题让品类与关键属性靠前，每点一个主题，按客户利益、事实依据、使用场景组织。视证据明确尺寸、兼容、数量、使用限制。补产品描述或 A+ 文案框架，包含用法、结构、变体差异及 FAQ。根据站点、类目已核验规则检查，规则未知时标注待复核。

- **交付与验收**：3 个标题、2 套五点、描述或 A+ 框架及关键词覆盖表。五点依次考虑核心价值、功能或材质、规格或兼容、场景和操作、包装或注意事项。需要时为日站、美站附中文对照。所有规格和承诺均核对事实来源。

### 可复制提示词｜标题

```text
输入站点、品类、品牌、已核验的标题限制、已确认事实、核心词和禁用表达。
输出 A 关键词覆盖型、B 核心卖点型、C 规格清晰型标题，各标注策略、已覆盖词和事实编号。
核心品类自然靠前，优先呈现影响购买的规格，使用目标市场的自然表达，不堆同义词。只写已确认的功能、参数、认证和效果。
```

### 可复制提示词｜五点与描述

```text
输入事实表、布局表、目标客户、购买动机、主要顾虑、差评与退货原因及禁用表达。
输出 A 功能与差异版和 B 场景与顾虑版，各五条并附关键词覆盖表。每条一个主题，写明客户利益、事实依据及适用场景。
按需写清尺寸、兼容范围、数量、配件和限制。所有测试、认证和售后承诺须有依据。
再给产品描述或 A+ 文案框架，包含场景、使用步骤、结构、变体差异、适用范围和 FAQ。
```

## 阶段 7｜生成图片、视频与 A+ Brief

规划七图：主图产品和实收数量、核心卖点、功能/材质、尺寸/兼容、场景、操作、包装/注意事项。逐张给客户问题、构图、目标市场标题与辅助文案、事实编号、必展示细节、拍摄素材和风险。给真实使用过程的视频方案及 A+ 模块顺序、主题、文案、素材与购买顾虑。交付后核对颜色、结构、尺寸、配件、对比证据、图文一致性及主图规则。

- **交付与验收**：七图、视频和 A+ Brief。A+ 用模块顺序｜主题｜文案｜所需素材｜解决的顾虑记录，设计交付后复核实物、配件、尺寸、证据与站点规则。

## 阶段 8｜整理 Search Terms

基于选定前台版本补高相关未覆盖表达，排重并去除竞品品牌、ASIN、未经授权的商标、低相关词及不存在的功能。输出候选、来源、删词理由和风险词。说明需由运营按当前 Seller Central 站点和类目要求确认长度、计量单位与格式。

- **交付与验收**：候选版本｜词源｜删词与理由｜风险词｜待核验要求。绑定采用的标题和五点版本，由运营核验当前长度与格式。

### 可复制提示词｜Search Terms

```text
输入目标站点、选定标题、五点和关键词布局表。
补充高相关且未自然覆盖的表达，去重，排除竞品品牌、ASIN、未经授权商标、低相关词和产品不具备的属性。
输出候选版本、关键词来源、删除词、删除原因和风险词。当前 Seller Central 长度及格式由运营核验。
```

## 阶段 9｜三轮审核

逐轮记录审核人、日期和结论。事实轮核对规格、配件、认证和限制。语言与转化轮检查本土表达、品类清晰度、顾虑覆盖、堆词、误购和图文一致。合规初审检查绝对化、无证效果、医疗健康安全、认证、商标和平台要求。风险分高（修复前阻止发布）、中（负责人确认）、低（表达优化）、待核实（须人工验证）。侵权、认证或安全疑点交专业人员。合规初审不可视为批准。

- **交付与验收**：检查清单含位置、原文、风险、依据、建议和人工结论。高风险修复后复核，中风险负责人确认，资料不足查证。

### 三轮审核清单

| 轮次 | 检查项目 |
| --- | --- |
| 产品事实 | 材质、尺寸、数量、重量、功能、兼容、配件、包装、认证、使用限制 |
| 语言与转化 | 品类、卖点、顾虑、堆词、本土表达、误购和各版块一致性 |
| 合规 | 无证参数和效果、夸大与绝对化、医疗健康安全、认证、第三方品牌和当前类目规则 |

### 可复制提示词｜合规风险初审

```text
用已确认事实表、站点和类目规则审核标题、五点、图片、A+ 和 Search Terms。
检查无证宣称、绝对化词、健康安全及认证、商标、跨模块信息矛盾、规格兼容错误、堆词和误购风险。
输出位置、原文、风险等级、问题依据、修改建议、是否须人工复核。
高风险修复前阻止发布，中风险提交负责人确认，低风险提出表达优化。待核实项目查证后再判断。
```

## 阶段 10｜发布与版本记录

## 阶段 11｜数据追踪与复盘

在 7、14、28 天分阶段复盘，按样本调整观察窗口。使用同站点、同变体及可比时间段，记录自然与广告指标口径和分母、价格、活动、库存、广告结构及季节变化。曝光升但 CTR 降时查流量相关性和主图；CTR 升但 CVR 降时查预期、价格与页面；销量升且退货升时查误购；广告 CVR 升且 ACoS 降时观察自然侧变化。样本少时延长观察，相关变化仅支持趋势或待验证假设。

- **交付与验收**：保存 Sessions、Unit Session Percentage、广告曝光、CTR、CVR、ACoS、TACoS、核心词排名、订单、退货率、退货原因和低星主题。7 天看趋势，14 天比流量、点击与转化，28 天形成阶段结论。经营表现可按 [经营表现评分](listing-audit.md#经营表现评分) 单列。

### 数据复盘判断表

| 观察结果 | 待验证解释 | 下一步 |
| --- | --- | --- |
| 曝光增、CTR 降 | 流量扩展后精准度下降 | 查关键词和主图 |
| CTR 升、CVR 降 | 点击预期与页面不匹配 | 查承诺、价格和页面 |
| Sessions 稳定、页面转化升 | 页面信息可能改善决策 | 保留版本并持续观察 |
| 销量升、退货率升 | 误购或页内限制说明不足 | 核对尺寸、兼容和退货原因 |
| 广告 CVR 升、ACoS 降 | 流量与页面匹配可能改善 | 对照自然侧表现 |
| 变化不明显 | 样本不足或改动影响有限 | 延长观察或选择下一变量 |

## 执行看板与归档

看板状态依次使用待收集、待诊断、待确认、文案中、设计中、待审核、待发布、观察中、已完成。每条任务记录负责人、下一步和需要确认的资料。

按站点和 ASIN/SKU 归档任务单、事实表、关键词布局、评论与退货分析、竞品对比、文案候选、图片与 A+ Brief、Search Terms、审核清单、发布记录及数据复盘。字段见 [交付模板](templates.md)。

### 每日执行看板

| 状态 | 当前动作 |
| --- | --- |
| 待收集 | 核实事实，补齐关键词、评论与竞品资料 |
| 待诊断 | AI 检查现页并评分 |
| 待确认 | 运营确认修改方向 |
| 文案中 | 生成标题、五点、描述或 A+ |
| 设计中 | 制作图片、视频和 A+ |
| 待审核 | 完成事实、语言与合规审核 |
| 待发布 | 等待负责人批准 |
| 观察中 | 检查前台并追踪数据 |
| 已完成 | 记录阶段性复盘结论 |

### 简版 SOP

1. 填写任务单，选定唯一主目标。
2. 核实事实表，导入关键词、评论和页面资料。
3. AI 先做百分制诊断，运营确认优先项。
4. 输出 3 个标题、2 套五点、图片与 A+ Brief 及 Search Terms。
5. 三轮审核，负责人确认后发布并保存版本。
6. 上线后 1–2 天检查页面，7／14／28 天复盘。
